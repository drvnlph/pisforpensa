# P is for Pensa

**Можно ли верить Дмитрию Пчелинцеву?** Реакция на текст «Первого отдела»
о деле «Сети», и сканы тома 28 материалов дела.

Опубликовано: <https://drvnlph.github.io/pisforpensa/>

Статический сайт — без сборки и зависимостей. Дизайн-система взята
из `sample_lorem` (репозиторий `personal-tools`), сканы — из репозитория
`correspondence`.

## Структура

```
style.css    <- дизайн-система: токены, темы, компоненты
app.js       <- читательский интерфейс: прогресс, оглавление, сноски, настройки
index.html   <- разбор
scans.html   <- просмотр сканов тома 28
scans/       <- 54 скана + tom-28.pdf
```

## Дизайн-система

Три темы шрифтов (`data-font`), четыре цветовые (`data-color`), три режима
оформления ссылок (`data-links`) — переключаются в подвале и сохраняются
в `localStorage`.

Блоки: `.source-quote`, `.explainer`, `.key-points`, `.timeline`,
`.pullquote`, `.marginalia`, `.def-list`, `.collapsible`, `.preface`,
`.draft-note`, `.gap`, `.sensitive` (размытие до клика), сноски `.fn-ref`
со всплывающими подсказками и дублированием внизу страницы.

## Оглавление

Единственный источник — список `#tocDesktopList` в `index.html`.
Мобильное выпадающее меню, встроенное оглавление и подписи в мобильной
шапке собираются из него автоматически. Редактировать нужно только его.

## Сканы

Том 28: протокол осмотра предметов от 18 июня 2018 (осмотр телефона,
изъятого у Андрея Чернова) и приложение №1 на 53 листах — переписки
из `base-keepas.kdbx`. Всего 54 листа.

Список страниц в `scans.html` — это массив `PAGES`; имена файлов
выводятся из него. Чтобы добавить или убрать лист, правится только массив.
