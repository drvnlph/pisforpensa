# P is for Pensa

**Можно ли верить Дмитрию Пчелинцеву?** Реакция на текст «Первого отдела»
о деле «Сети», и сканы тома 28 материалов дела.

Опубликовано: <https://drvnlph.github.io/pisforpensa/>

Статический сайт — без сборки и зависимостей. Дизайн-система взята
из `sample_lorem` (репозиторий `personal-tools`), сканы — из репозитория
`correspondence`.

## Структура

```
style.css    <- дизайн-система: токены, темы, компоненты
fonts.css    <- локальные Source Serif 4, Source Sans 3 и IBM Plex Mono
app.js       <- читательский интерфейс: прогресс, оглавление, сноски, настройки
index.html   <- разбор
scans.html   <- просмотр сканов тома 28
scans/       <- 54 скана + PDF с текстовым слоем + расшифровка
scripts/     <- автоматические проверки сайта и архива
```

## Дизайн-система

Единая типографическая система: Source Serif 4 для статьи, Source Sans 3
для навигации и интерфейса, IBM Plex Mono для расшифровок и технических
данных. Шрифты и лицензии хранятся локально в `fonts/`; запросов к Google
Fonts нет. Четыре цветовые темы (`data-color`) и три режима оформления
ссылок (`data-links`) переключаются в подвале и сохраняются в `localStorage`.

Основной словарь компонентов намеренно небольшой: `.preface` для позиции
авторов, `.framing` для резюме и списков тезисов, `.claim-details` для
раскрываемой версии оппонента, `.quote` с вариантами `.quote-source` и
`.quote-prominent`, семантический `.glossary`, `.timeline`, связанная с
просмотрщиком `.archive-figure` и авторская разметка `.editor-note`.
Сноски `.fn-ref` открываются рядом с текстом и дублируются внизу страницы.
Отдельный блок авторов появится только после согласования подписи, имен или
псевдонимов; сейчас эту роль честно выполняет предисловие «Кто мы такие?».

`.archive-figure` повторяет устройство архива: узкая информационная панель,
нейтральный холст и белый «лист» с легкой тенью. Для пары фотографий нужно
добавить `.figure-pair` к `.archive-figure-canvas`; на телефоне они встанут
друг под другом. Ссылка в панели может вести на конкретный `scans.html#42`.

## Оглавление

Единственный источник — список `#tocDesktopList` в `index.html`.
Мобильное выпадающее меню, встроенное оглавление и подписи в мобильной
шапке собираются из него автоматически. Редактировать нужно только его.
Архив тома 28 показан отдельной каталоговой строкой под содержанием и
намеренно не входит в нумерованный список разделов.
Словарь имен имеет отдельный якорь `#names` и вложенный пункт оглавления;
фильтры персон в архиве возвращают читателя именно к нему.

## Сканы

Том 28: протокол осмотра предметов от 18 июня 2018 (осмотр телефона,
изъятого у Андрея Чернова) и приложение №1 на 53 листах — переписки
из `base-keepas.kdbx`. Всего 54 листа.

Список страниц в `scans.html` — это массив `PAGES`; имена файлов
выводятся из него. Чтобы добавить или убрать лист, правится только массив.

`scans/tom-28.pdf` сохраняет исходные изображения и содержит невидимый,
доступный для поиска русский текстовый слой. В просмотрщике тот же текст
открывается кнопкой «Текст». Поле «Лист» в верхней панели принимает физический
номер листа (`3` или `6`–`58`) и синхронизируется с хэшем страницы; клавиша
`G` переводит в него фокус. Поле поиска ищет сразу по всем 54 листам;
результат открывает нужный скан и подсвечивает совпадение в расшифровке.
Поиск можно сохранить в ссылке как `scans.html?q=фраза#42`. Ссылки из
словаря имен используют курируемые объединения псевдонимов вида
`scans.html?person=pchelintsev#9`: просмотрщик показывает все относящиеся
к человеку листы и отдельно помечает вероятные однобуквенные псевдонимы,
продолжения записей и случаи использования чужого аккаунта.
Полная расшифровка доступна отдельно в
`scans/tom-28.txt`; данные для отдельных страниц лежат в
`scans/transcriptions.js`. Закрытые печатями или действительно неразборчивые
фрагменты помечены как `[неразборчиво]`.

В статье ссылки на доказательные места размечаются как
`<a class="scan-cite" href="scans.html#42">лист 42</a>`. Хэш всегда равен
номеру файла скана без ведущих нулей.

## Проверки

Локально:

```sh
bash scripts/check-site.sh
```

Скрипт проверяет синтаксис JavaScript, локальные ссылки и хэши, уникальность
`id`, метаданные и локальные шрифты, отсутствие Unicode-стрелок в интерфейсе,
точное совпадение 54 JPEG, 54 расшифровок и массива `PAGES`, число страниц
PDF и близость его текстового слоя к ручной расшифровке. Та же команда
запускается в GitHub Actions для каждого pull request и push в `main`.
